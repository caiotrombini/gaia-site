# Gaia Escola de Astrologia

Site estatico profissional para a Gaia Escola de Astrologia com:

- pagina institucional;
- pagina do aluno Guilherme Rodrigues;
- imagem de identificacao academica em `assets/`;
- configuracao simples para deploy na Vercel.

Abra `index.html` diretamente ou sirva a pasta com um servidor HTTP.
